# /handoff

현재 세션의 대화 내용과 git 상태를 바탕으로 HANDOFF.md 초안을 작성하고,
사용자 확인 후 루트에 저장한다.

## 절차

### 1. git 상태 수집

아래 명령을 실행해 현재 상태를 파악한다.

```bash
git branch --show-current
git status --short
git diff --stat HEAD
```

### 2. HANDOFF.md 초안 작성

수집한 git 정보와 **현재 세션의 대화 내용 전체**를 바탕으로 아래 6섹션을 채운다.
각 섹션은 구체적이어야 한다 — 파일명, 함수명, 결정 근거까지 포함할 것.

```markdown
# Handoff — {오늘 날짜 YYYY-MM-DD}

## 브랜치 & 상태
- 브랜치: `<branch>`
- 변경 파일: <git status --short 결과 요약>

## 이번 세션에서 한 일
- <완료된 작업 1 (파일명·함수명 포함)>
- <완료된 작업 2>
- ...

## 변경된 핵심 파일
- `<경로>` — <한 줄 설명>
- ...

## 다음에 할 일
- <남은 작업 또는 사용자가 언급한 다음 단계>
- ...

## 중요 결정 & 제약
- <이 세션에서 발견한 제약, 선택한 접근법, 주의사항>
- ...

## 새 세션 시작 힌트
@HANDOFF.md 참고해서 이어서 작업해줘. <작업 내용 한 줄 요약>.
```

- 내용이 없는 섹션은 `(해당 없음)`으로 표기한다.
- 없는 내용을 추측해서 채우지 않는다.

### 3. 초안 출력

작성한 HANDOFF.md 전체 내용을 마크다운 코드블록으로 사용자에게 보여준다.

### 4. 사용자 확인

`AskUserQuestion` 도구로 아래 질문을 한다.

- 질문: `위 내용으로 HANDOFF.md를 저장할까요?`
- 선택지:
  - `Yes` — HANDOFF.md 저장
  - `No` — 취소

### 5-A. Yes 선택 시

1. `Write` 도구로 프로젝트 루트 `HANDOFF.md`를 덮어쓴다.
2. 아래 메시지를 출력한다.

```
HANDOFF.md 저장 완료.
이제 /clear 를 입력해 세션을 종료하세요.
새 세션에서 "@HANDOFF.md 참고해서 이어서 작업해줘"라고 시작하면 됩니다.
```

### 5-B. No 선택 시

아래 메시지를 출력하고 종료한다.

```
handoff를 취소했습니다. HANDOFF.md는 저장되지 않았습니다.
```

## 금지

- `git commit`, `git push` 금지
- HANDOFF.md 외 다른 파일 수정 금지
- 세션에 없던 내용 추측해서 추가 금지
- No 선택 시 파일 쓰기 금지
