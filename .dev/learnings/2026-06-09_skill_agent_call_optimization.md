# /test·/e2e 스킬에서 에이전트 중복 호출로 인한 토큰 낭비

> 작성일: 2026-06-09
> 브랜치: `chore/15-harness-structure-optimization`
> 결론: **스킬 내 에이전트는 역할별 1회만 호출하고, 컨텍스트는 파일 내용 대신 경로로 전달**

## 증상 / 문제
- `/test` 스킬: test-engineer 에이전트가 3단계(케이스 설계)와 6단계(파일 작성)에서 두 번 호출됨
- `/e2e` 스킬: 시나리오 도출을 test-engineer에 위임(2단계)하고 이후 qa-tester에 파일 내용 전체를 전달 → 토큰 두 배 이상 소모
- 스킬 1회 실행에 토큰 사용량이 매우 높아 실용성 저하

## 원인 / 패턴
- 단계를 세분화할수록 에이전트 호출 횟수가 늘어나고 컨텍스트가 중복 전달됨
- 에이전트에 파일 내용 전체를 인라인으로 포함하면 입력 토큰이 파일 크기만큼 추가됨

## 결론 및 참고
- **에이전트 통합**: 설계→작성처럼 순서가 이어지는 단계는 1회 호출로 통합
  (`test-engineer`가 케이스 설계 + 파일 작성을 한 번에 처리)
- **경로 전달**: 에이전트에게 파일 내용 대신 절대 경로만 전달 — 에이전트가 필요 시 직접 Read
- 적용 파일: `.claude/commands/test.md`, `.claude/commands/e2e.md`
